AppServerSession：`codex.exe app-server --listen stdio:// -c chatgpt_base_url="https://chatgpt.com/backend-api/" -c analytics.enabled=false -c mcp_servers={}`，工作目录 = SystemDrive 根。stdin/stdout 管道，stderr → NUL。状态机与 Swift 一致（id 1 initialize{clientInfo{name reset-rune,title "Bottled Reset Rune",version 0.1.2},capabilities{experimentalApi:true}} → initialized 通知 → id2 account/read{refreshToken:false} → id3 account/rateLimits/read → consume 时 id4 account/read 再核对 email（raw UTF-16 相等）→ may_send 门禁 → id5 account/rateLimitResetCredit/consume{creditId,idempotencyKey}）。帧 ≤ 1 MiB；整会话 deadline（发送 consume 前重置）；服务端带 id 的请求 → protocol-error；expectedId≥3 后收到 account/updated → consume 中 identity-changed、读取中 read-failed；结果映射 reset/alreadyRedeemed/nothingToReset/noCredit。preflight 顺序与错误码完全照 Swift preflightAndSend：identity-unavailable、identity-changed、preflight-ineligible、expired、credit-unavailable、cancelled。RuneError.not_sent 只在 consume 请求尚未写出时为 true。
