3c. 托盘与面板（Win32，无框架）—— ui/tray.rs、ui/panel.rs、ui/controls.rs、ui/theme.rs
- 托盘：三态图标（stored/empty/unknown）由 PanelState.bottle 决定；tooltip = 状态文案；左键打开/关闭面板；右键菜单 Open / Check connection / Quit menu bar interface（退出托盘不停止后台，菜单项注释 quitNote）；TaskbarCreated 重建；订阅 worker 管道（subscribe 推送），断线显示 disconnected/stale 文案并以 5s/10s/30s 退避重连（无固定心跳）。
- 面板：368 DIP 宽的弹出窗口（WS_POPUP | WS_BORDER，圆角用 DWMWA_WINDOW_CORNER_PREFERENCE），定位在托盘图标附近（Shell_NotifyIconGetRect + 工作区边界，支持任务栏在四边与多屏），失焦（WM_ACTIVATE inactive）或 Esc 关闭；DPI 100–300%（WM_DPICHANGED 重建布局与字体）；系统字体 Segoe UI（SystemParametersInfo NONCLIENTMETRICS），品牌字标用 Georgia 或 Cambria。
- 内容（design/README.md）：顶部魔瓶物品图（自绘，按状态切换）+ 一句 intro；"自动使用" 开关（真实 BS_AUTOCHECKBOX 或 toggle 风格的 owner-draw 按钮但保留 BS_CHECKBOX 语义与 UIA 角色）；摘要行（收起：最近到期 nextCredit；展开：库存数量）点击展开明细列表（每行 28px reset-rune 图 + 名称 + 右对齐日期，行高 44，同分钟合并计数；unknown 行）；蓝量条（自绘渐变 #1056DB→#73F5FE，文字百分比）；尝试时机一行；账号行（email 或 noIdentity）；三个互斥展开区：设置（提前量 5/10/30/60 下拉或单选、语言、外观、登录启动、通知复选；settingsNote）、记录/战报（recent_events，成功用 dota-success.png，每条有文字）、以及 mock 提示 mockNote。
- 开启自动使用流程：点击开关 → 若 status 需要绑定（binding 为空）先弹 bindTitle 确认 → 从 worker 取 consent → config{enabled:true, consent}；错误映射到 saveFailed/bindRequired/identityUnavailable/consentRequired/pauseFirst 文案并显示在面板内（不弹系统对话框）。暂停 → config{enabled:false}；若返回 pause-not-persisted 显示 "暂停未保存，跨重启无法保证" 与 "停止后台" 按钮（调用 CLI stop 语义）。
- 主题：theme.md 色表（浅/深），appearance=system 时跟随 UISettings 或注册表 AppsUseLightTheme（WM_SETTINGCHANGE "ImmersiveColorSet" 时刷新）；系统高对比度（SystemParametersInfo SPI_GETHIGHCONTRAST）开启时放弃装饰色，用系统颜色（GetSysColor）。深色标题栏用 DWMWA_USE_IMMERSIVE_DARK_MODE（文档化属性 20），不用未文档化序号。
- 辅助功能：所有控件为真实 Win32 控件或带 UIA 属性的 owner-draw 按钮；Tab/Shift+Tab 循环焦点，Space/Enter 激活，Esc 关闭，焦点矩形可见；自绘元素设置可访问名称（通过 SetWindowText 或 IAccPropServices 简化为同名静态控件）。
- 通知：reset 成功且 notify=true 时，用 Shell_NotifyIconW NIF_INFO 气泡（标题 "Bottled Reset Rune"，正文中英文同 Service.swift 第 98-100 行）；不泄露邮箱；通知失败不改回执。记录决策：Toast/AUMID 作为后续改进（不引入 WinRT 运行时依赖体积前先用气泡）。
