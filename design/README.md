# Bottled Reset Rune 界面

一个约 368px 宽的 macOS 原生菜单栏面板。魔瓶承载库存状态，日常界面保持一句用途说明、一个自动使用开关、最近到期摘要和当前账号。设置、明细与战报按需就地展开。

## 对外文案

GitHub、项目首页与宣传页使用以下主句：

- 中文：把codex的重置变成神符装进魔瓶
- English: Turn your Codex resets into bottled runes.

主句下方解释每枚重置神符（Reset Rune）代表一次 Codex 备用重置，以及开启后应用会在到期前尝试使用。应用内用功能文案说明授权和操作结果。

- `../native/Sources/RuneMenu/PanelState.swift`：展示模型与中英文文案。
- `../native/Sources/RuneMenu/main.swift`：菜单栏图标和窗口生命周期。

- `../assets/icons/`：应用图标及三种菜单栏状态图。素材出处、适配与权利归属见[美术来源](../assets/ARTWORK.md)。

- `../.impeccable.md`：用户、品牌语气和设计原则。

## 库存与操作

重置神符数量大于零时显示 Dota 2 的瓶装恢复符，零库存显示原版空瓶。库存未知、读取失败、身份变化或结果未确认时使用待确认标记。库存与自动使用开关分别展示，到期明细不完整时仍展示已知次数。

菜单栏使用同源的彩色小图标区分有符、空瓶和待确认，辅助功能标签说明当前状态。Finder 使用固定应用图标。

点击摘要展开重置神符明细。每行依次显示 28pt 的重置神符小图、名称和右对齐的到期日期，行高 44pt。同一分钟到期的神符合并一行，在名称旁标数量；缺少日期的库存显示一行「到期时间未知」。展开时摘要改为库存数量，收起后恢复最近到期时间。神符用途在悬停帮助中显示。蓝量条表示主额度窗口的剩余比例，尝试时机只用一行说明。战报按最新时间排列最近操作；结果不同必须有可读文字，不能仅依赖颜色或游戏图形。

## 设置

提前量可选 5、10、30、60 分钟。语言提供 English 与简体中文，默认英文；外观提供跟随系统、浅色、深色，默认跟随系统。设置即时保存，语言和外观不改变自动使用授权或提前量。

窗口隐藏时不保持网页或视图定时刷新；状态由本机后台推送。主面板没有逐秒倒计时、常驻动画、音效或额外导航页面。

## 设计验证

示意和检查仅使用合成账号、库存与时间。覆盖中英文、深浅色、键盘、长文案、三种库存状态、设置与记录互斥展开。验证方法见[验证范围](../docs/acceptance-matrix.md)。

## 信使任务（Codex 已接入，尚未实发验收）

已确定方向为「信使任务 / Courier Tasks」：定时向用户明确选定的 Codex／Claude Desktop Code 聊天发送文本，记录派发结果，不表示 Agent 工作已完成。魔瓶与蓝量继续表示备用重置和额度，信使功能单独授权；其等待或异常不改变库存图含义。

主面板已增加摘要与入口；列表、编辑器和派发记录放独立原生管理窗。这是单面板约定的局部扩展，不为普通设置、神符明细增加页面。关闭面板保留宿主，退出主应用后等待重开并按最晚发送时间处理。Codex 原生通道无需辅助功能，只有已锁定并只读核对的版本允许用户明确启用；未知版本与未验收 Claude 保持阻断。界面区分“只读已核对”与“尚未实发验收”。

表单使用「目标应用」「目标聊天」「发送文本」「发送时间」等普通语言，不另设任务名称输入；列表和记录直接显示发送文本摘要。发送时间下只用一句话说明固定 15 分钟补发期限，不另设「允许延后发送」和最晚时间设置；派发记录保留最晚发送时间用于核对。保存区只有「保存」，点击后自动启用任务和信使派发，不提供保存为暂停。保存前用简短说明明确启用效果；已有任务仍可随时暂停。结果使用「已发送」「发送结果待确认」，不使用「执行完成」。不增加常驻动画或游戏养成；入口使用系统纸飞机符号，没有新增 Dota 美术。范围与验收见[开发计划](../docs/courier-development-plan.md)，实现边界见[技术方案](../docs/courier-technical-design.md)与[兼容核对](../docs/courier-compatibility.md)。
