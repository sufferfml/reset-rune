# Bottled Reset Rune 界面

一个约 368px 宽的 macOS 原生菜单栏面板。魔瓶承载库存状态，日常界面保持一句用途说明、一个自动使用开关、最近到期摘要和当前账号。设置、明细与战报按需就地展开。

## 对外文案

GitHub、项目首页与宣传页使用以下主句：

- 中文：把codex的重置变成神符装进魔瓶
- English: Turn your Codex resets into bottled runes.

主句下方解释每枚重置神符（Reset Rune）代表一次 Codex 备用重置，以及开启后应用会在到期前尝试使用。应用内用功能文案说明授权和操作结果。

## 库存与操作

重置神符数量大于零时显示 Dota 2 的瓶装恢复符，零库存显示原版空瓶。库存未知、读取失败、身份变化或结果未确认时使用待确认标记。库存与自动使用开关分别展示，到期明细不完整时仍展示已知次数。

菜单栏使用同源的彩色小图标区分有符、空瓶和待确认，辅助功能标签说明当前状态。Finder 使用固定应用图标。

点击摘要展开重置神符明细。每行依次显示 28pt 的重置神符小图、名称和右对齐的到期日期，行高 44pt。同一分钟到期的神符合并一行，在名称旁标数量；缺少日期的库存显示一行「到期时间未知」。展开时摘要改为库存数量，收起后恢复最近到期时间。神符用途在悬停帮助中显示。蓝量条表示主额度窗口的剩余比例，尝试时机只用一行说明。战报按最新时间排列最近操作；结果不同必须有可读文字，不能仅依赖颜色或游戏图形。

## 设置

提前量可选 5、10、30、60 分钟。语言提供 English 与简体中文，默认英文；外观提供跟随系统、浅色、深色，默认跟随系统。设置即时保存，语言和外观不改变自动使用授权或提前量。

窗口隐藏时不保持网页或视图定时刷新；状态由本机后台推送。主面板没有逐秒倒计时、常驻动画、音效或额外导航页面。

## 设计验证

示意和检查仅使用合成账号、库存与时间。覆盖中英文、深浅色、键盘、长文案、三种库存状态、设置与记录互斥展开。验证方法见[验证范围](../docs/acceptance-matrix.md)。
