# Panel art

The inventory row uses the Valve item artwork in `bottle.png` and `bottle-empty.png`. Both are opaque 88 × 64 inventory illustrations. Show the unconfirmed state with the empty plate and a visible status mark.

Expanded inventory rows display the custom `reset-rune.png` illustration at 28 pt beside the item name and expiry. `dota-texture.jpg` and `dota-divider.png` preserve compact exports of Valve’s website texture and divider. The battle log uses the TI10 checkmark in `dota-success.png` for a successful redemption. Source URLs, attribution and image transformations are recorded in [Artwork and sources](../ARTWORK.md). See the [icon guide](../icons/README.md) for Finder and menu bar representations.
